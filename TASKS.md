# Задачи И16

Начинайте с первой задачи, для которой готовы зависимости. Идентификаторы `FR` соответствуют требованиям [спецификации](SPEC.md), а `A` и `V` — [критериям приёмки](docs/acceptance.md).

| Задача | Этап | Требования | Зависимости | Готовый результат и проверка |
| --- | --- | --- | --- | --- |
| T01. Загрузить и проверить срезы | 1 | FR-01, FR-04 | [Контракт данных](docs/data-contract.md) | Демонабор читается, нарушение контракта даёт диагностируемую ошибку. A07. |
| T02. Рассчитать сравнение за год | 1 | FR-02 | T01 | Опубликованные места, ничья, разброс и пропуски совпадают с ожидаемыми результатами. A01, A02, A06, A10. |
| T03. Собрать CLI и Markdown | 1 | FR-01, FR-02, FR-04 | T01, T02 | CLI выдаёт детерминированную справку за год и корректно обрабатывает ошибки записи. A01, A02, A06, A07, A10, A11. |
| T04. Рассчитать динамику | 2 | FR-03, FR-04 | T03 | Сопоставимые срезы дают эталонные дельты, для остальных случаев выводятся доступные значения и причины ограничений. A03–A05, A08, A09. |
| T05. Подготовить визуальный ориентир | Параллельно этапам 1–2 | FR-05 | Брендбук и демонабор | [HTML-макет](examples/rating-preview.html) показывает оформление на данных эталона. V01–V04. |
| T06. Подготовить PostgreSQL и импорт | 3 | FR-06 | T01, [архитектура](docs/architecture.md) | Миграции разворачивают схему, демонабор загружается атомарно и без дублей. A12. |
| T07. Реализовать HTTP API | 3 | FR-07, FR-09 | T06, T11 | Справочники, сравнение и разрывы доступны через API. Сравнение с базой совпадает с результатом CLI. A13, A14, A18, A19. |
| T08. Реализовать веб-клиент | 3 | FR-05, FR-08, FR-09 | T05, T07 | В браузере работают выбор опорного субъекта и сравнение. В частичной справке видны ограничения. A15, A16, A18 и V01–V04. |
| T09. Провести пилот | 4 | FR-01–FR-11 | T10, T12, T13 | [Сценарий защиты](docs/pilot-ria.md) пройден, веб-справка сверена с источником и принята читателем. A17. |
| T10. Подготовить данные защиты | 0 | FR-01, FR-06 | Публикации РИА Рейтинг и таблица с точными значениями | [Выборка в JSON](examples/ria-pilot-dataset.json) и описание её происхождения доступны. Контроль для A17. |
| T11. Рассчитать разрывы по баллам | 2 | FR-09 | T04 | CLI с `--focus-subject` показывает разрывы и динамику по парам. A18, A19. |
| T12. Собрать справку с помощью ИИ | 3 | FR-10 | T07, T08 | Веб-клиент запрашивает итог с ИИ. Сервер проверяет выбранные факты и возвращает шаблон при сбое. A20, A21. |
| T13. Показать аналитический дашборд | 3 | FR-11 | T08 | По тем же данным API показаны баллы, динамика и разрывы. Графики реагируют на фильтры и сохраняют пропуски. A22–A24. |

CLI, PostgreSQL, HTTP API и веб-клиент реализованы. CLI проверен по эталону, PostgreSQL — на повторном импорте, API — на чтении после перезапуска. Для T12 пройдены проверки с тестовым провайдером и без настроенного провайдера. Для T13 в Safari проверены графики до и после выбора базы и добавления регионов. Отдельно проверены состояния графика для нуля, пропуска и несопоставимых значений. T09 остаётся открытой до показа читателю и проверки живой модели в среде пилота.
