# Шаблон справки И16

1. **Заголовок и контекст.** Название рейтинга, текущий период, выбранная база при наличии, размер опубликованного рейтинга за каждый представленный период. Для `data_kind: demo` поставьте заметную отметку «Демонстрационные данные» сразу под заголовком.
2. **Краткий итог.** Назовите лидеров среди выбранных и разброс баллов, если эти сравнения доступны. Для динамики выделите наибольшее улучшение и наибольшее ухудшение места, когда они есть. Укажите изменение балла для тех же субъектов, если оно доступно. При равенстве дельт перечислите субъектов в порядке ID. Если доступна только динамика баллов, выделите наибольший рост и падение балла. При неполном покрытии укажите доступное число наблюдений. Если подтверждённого сравнения нет, опишите, какие данные представлены.
3. **Таблица сравнения.** Одна строка на каждый выбранный субъект. Включите имя и ID, места и баллы за текущий период. При указанной базе добавьте её места, баллы и обе дельты. Порядок строк задан в [спецификации](../SPEC.md).
4. **Ограничения.** Если справка частичная, укажите, каких значений не хватает или какие дельты недоступны и по какой причине. Полной справке отдельный раздел ограничений не нужен.
5. **Источники.** Для каждого показанного периода укажите название источника, ссылку на публикацию или путь к файлу от корня проекта, дату публикации и версию методики. При наличии `data_reference` дайте отдельную ссылку на таблицу с точными значениями.

Баллы и их дельты выводите с запятой и двумя цифрами после неё. Для положительных дельт добавляйте `+`, для отрицательных `−`, для нулевых выводите `0` или `0,00` без знака. `—` обозначает недоступное значение. Заголовки столбцов содержат единицы. Для дельты места укажите в справке, что плюс означает улучшение. Текстовые поля экранируйте так, чтобы они корректно отображались в Markdown, в том числе внутри ячеек таблицы.

Если выбран опорный субъект, после основной таблицы добавьте доступные разрывы по баллам. В тексте укажите, кто опережает кого, и величину разрыва. Для справки через ИИ коротко укажите способ формирования итога. Таблицы, ограничения и источники формируются сервером.
