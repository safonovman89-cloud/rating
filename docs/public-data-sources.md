# Открытая статистика регионов для И16

В сравнении РИА раздел «Дополнительные показатели регионов» показывает значения для выбранных субъектов. Каждый ряд имеет свой период, единицу и ссылку на публикацию. Места и баллы РИА рассчитываются по [правилам пилота](pilot-ria.md). Дополнительная статистика в них не входит.

Ряды сопоставлены по стабильным ID И16. Для рождаемости, топлива и индекса ИИ использованы строки Тюменской и Архангельской областей без входящих автономных округов. Округа имеют собственные строки. Сверочные значения для ЯНАО за 2024 год составляют 12,8 родившегося на 1 000 жителей и 57,30 ₽/л для АИ‑92. За декабрь 2025 года цена АИ‑92 составляет 62,86 ₽/л. В индексе активности у округа 83-е место и 74,96 балла, в февральской публикации о внедрении у него 19 решений и 4-е место среди пяти лидеров.

Панель [национального портала ИИ](https://ai.gov.ru/dashboard) отдельно показывает сведения о вариантах использования. У неё другой объект подсчёта, поэтому её данные не добавляются в февральский ряд. Для операторских карт доля жителей в зоне сигнала, доля покрытой площади и число абонентов являются разными показателями. При оценке возможного ряда сверяйте единицу и географию в метаданных [ЦУР 9.c.1 Росстата](https://rosstat.gov.ru/sdg/data/goal9).

## Подготовка данных для сервера

Храните локальную нормализованную выгрузку отдельно от репозитория. В скопированной таблице исключите итоговые строки России и федеральных округов, сопоставьте каждый регион со справочником РИА, сверяйте состав и контрольные значения. Для каждого ряда перенесите период наблюдения, единицу, полный адрес публикации и примечание о методике по [контракту](data-contract.md#дополнительные-показатели-регионов). Для топлива выберите столбцы АИ‑92 и дизеля, для рождаемости — первые два числовых столбца с коэффициентом родившихся, для индекса ИИ — опубликованное место и столбец «Итог». Смена года сравнения в интерфейсе сохраняет периоды этих выпусков.

Обычный `serve` читает `build/public-region-indicators.json` при запуске. Другой путь передаётся через `--public-indicators /путь/к/показателям.json`. После обновления файла перезапустите сервер. Карты связи доступны и без файла.

## Источники для расширения

| Источник | Подходящий ряд | Условие сопоставимости |
| --- | --- | --- |
| [Росстат, трудовые ресурсы](https://rosstat.gov.ru/labour_force) | Уровень безработицы, обследование рабочей силы | Сравнивать годовые средние доли рабочей силы 15 лет и старше. Разницу показывать в процентных пунктах. |
| [Росстат, национальные счета](https://rosstat.gov.ru/statistics/accounts) и [Тюменьстат, ВРП](https://72.rosstat.gov.ru/ofs_vya1) | ВРП на душу населения, тыс. руб. | Брать одинаковый год и выпуск. Для реального роста брать индекс физического объёма. |
| [Росстат, уровень жизни](https://www.rosstat.gov.ru/folder/13397) | Реальные денежные доходы населения по субъектам | Использовать одну методику и один период. Для индекса указывать базу сравнения. |
| [Росстат, инвестиции](https://www.rosstat.gov.ru/investment_nonfinancial) | Инвестиции в основной капитал по субъектам | Годовые суммы в текущих ценах и индекс физического объёма хранить отдельными рядами. |
| [Росстат, цены](https://www.rosstat.gov.ru/statistics/price) и [Банк России, региональная динамика цен](https://cbr.ru/statistics/ddkp/aipd/) | ИПЦ и инфляция в регионах | Сравнивать одинаковые месяцы и основания сравнения. Для инфляции год к году использовать ИПЦ к тому же месяцу прошлого года минус 100. |
| [Казначейство, консолидированные бюджеты субъектов](https://roskazna.gov.ru/ispolnenie-byudzhetov/konsolidirovannye-byudzhety-subektov-rossijskoj-federacii?filter_type=49) | Годовые доходы, расходы и сальдо бюджетов | Использовать один состав бюджетов и итоговый годовой отчёт. |
| [ФНС, Единый реестр МСП](https://rmsp.nalog.ru/statistics.html) | Количество субъектов МСП по категориям | Использовать снимок на одну дату. При нормировании сверять географию и период численности населения. |
