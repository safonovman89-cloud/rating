# Критерии приёмки И16

Исходная команда для этапа 2 приведена в [README](../README.md#локальный-cli). Для этапа 1 запускайте её без `--baseline 2024`. В сценариях с изменением набора работайте с копией [демофайла](../examples/demo-dataset.json). Все изменения в таблице независимы.

Автоматический прогон и параметры проверок полного набора и живой модели описаны в [README](../README.md#сквозные-тесты). Для закрытия A17 отдельно зафиксируйте результат показа читателю в целевой среде.
