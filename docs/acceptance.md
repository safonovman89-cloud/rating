# Критерии приёмки И16

Исходная команда для этапа 2 приведена в [README](../README.md). Для этапа 1 запускайте её без `--baseline 2024`. В сценариях с изменением набора работайте с копией [демофайла](../examples/demo-dataset.json). Все изменения в таблице независимы.

| ID | Проверка | Ожидаемый результат |
| --- | --- | --- |
| A01 | Выбрать `demo-a demo-b demo-c` за 2025 год без базы. | Строки A, B, C с местами `2, 2, 4` и баллами `82,50`, `82,50`, `78,00`. A и B названы лидерами выбранной группы, разброс `4,50` балла, размер рейтинга `4`. Базовых столбцов нет. |
| A02 | Повторить A01 с ID в обратном порядке. | Текст совпадает с A01. Демоотметка и источник с датой видны. |
| A03 | Выполнить A01 с `--baseline 2024`. | Дельты мест `+2`, `0`, `−1`. Дельты баллов `+6,50`, `−1,50`, `+1,00`. Справка совпадает с [эталоном](../examples/demo-brief.md). |
| A04 | В A03 сменить версию методики только у базы. Отдельно повторить с изменением только базового `score_max` с `100` на `110`. | Значения обоих периодов видны, все дельты `—`, указано, чем различаются срезы. Справка частичная. |
| A05 | В A03 сменить `cohort_id` только у базы при том же размере. Отдельно повторить с базовым `cohort_id: null` и с размером базы `5` при прежнем ID. | Дельты места `—`, причина указана, дельты баллов совпадают с A03. Справка частичная. |
| A06 | Для `demo-c` в текущем срезе установить `rank: null`, `score: 0` и выполнить A01. | Строка C сохранена, место `—`, балл `0,00`. Разброс `82,50`. A и B названы обладателями наивысшей из доступных позиций. Указано покрытие мест `2 из 3`. |
| A07 | Поочерёдно передать один ID, повторный ID, неизвестный ID, отсутствующий текущий период, повреждённый JSON или набор с повторной строкой в срезе. | Код `2`, сообщение с причиной в `stderr`. Новый файл не появляется. Существующий выходной файл сохраняется. |
| A08 | Удалить строку `demo-c` только из базы и выполнить A03. Отдельно повторить A03 с базовым `rank: null` и исходным баллом C. | В первом случае обе дельты C равны `—`, во втором скрыта только дельта места C. Остальные дельты и текущие выводы совпадают с A03. Справка частичная. |
| A09 | Передать `--baseline 2025` при текущем 2025. Отдельно проверить отсутствующий базовый год `2023`. | Код `2`, указана причина, состояние выходного файла совпадает с A07. |
| A10 | Оставить выбранным субъектам одно текущее место и убрать у них все баллы. Повторить без единого известного места. | Один факт даёт частичную справку без утверждения о лидерстве и без разброса. При полном отсутствии данных код `2` и выходной файл не создаётся. |
| A11 | Указать входной файл как выходной. Отдельно указать в качестве выхода существующий каталог. | В первом случае код `2`, входной файл не меняется. Во втором случае код `1`, справка не создаётся. |

Сверяйте числовые результаты с входными строками и формулами. Для ошибок проверяйте код завершения, сообщение и состояние выходного файла. Для успешных запусков ожидается код `0`.

## Визуальное оформление FR-05

| ID | Проверка | Ожидаемый результат |
| --- | --- | --- |
| V01 | Сверить макет с [гайдом](visual-style.md). | Титульный блок использует фирменный красный `#BF1238`. Светлые цвета и дисплейный шрифт применены по гайду. Демоотметка видна рядом с заголовком. |
| V02 | Сверить таблицу и источники с Markdown-эталоном. | Периоды, порядок строк, места, баллы, дельты и даты совпадают. Знаки `+`, `−` и `0` читаются без цветовых подсказок. |

| V04 | Открыть предварительный просмотр печати на A4 с отключённым фоном. | Все колонки, заголовки, знаки дельт и источники читаются. |

После реализации веб-клиента повторите V01–V04 на справке, сформированной через API.

## Веб-версия FR-06–FR-08

Используйте отдельную тестовую базу PostgreSQL и [демонабор](../examples/demo-dataset.json). Сценарии описывают результат этапа 3 из [плана](../PLAN.md).

| ID | Проверка | Ожидаемый результат |
| --- | --- | --- |
| A12 | Применить миграции на пустой базе. Загрузить демонабор дважды, затем попытаться загрузить копию с нарушением контракта. | В базе остаются один рейтинг, четыре субъекта, два годовых среза и восемь результатов. Повторная загрузка сохраняет значения, ошибка оставляет данные без изменений. |
| A13 | Запросить справочник и выполнить пример HTTP-запроса из [архитектуры](architecture.md). | API отдаёт годы `2025` и `2024` и четыре ID. Сравнение возвращает HTTP `200`, порядок строк, исходные значения, обе дельты и источники из A03. |
| A14 | Запросить сравнение для одного субъекта. Отдельно повторить корректный запрос при недоступной базе. | Сервер возвращает HTTP `400` для некорректных параметров и HTTP `503` при недоступной базе. Ответ объясняет причину. |
| A15 | В браузере выбрать `2025`, базу `2024` и `demo-a`, `demo-b`, `demo-c`, затем запустить сравнение. Повторить без базы. | Справка показывает итог, таблицу и источники, совпадающие с A03. Без базы показаны данные A01. |
| A16 | Открыть в веб-клиенте сравнение на данных из A05. Отдельно повторить запрос при недоступном сервере или базе. | При несопоставимом охвате видны доступные значения и причина пропуска дельты места. При сетевой или серверной ошибке отображается сообщение, форму можно отправить повторно. |
