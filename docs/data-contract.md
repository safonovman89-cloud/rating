# Контракт данных И16

Версия контракта `1`. Вход — один JSON-файл в UTF-8. Каждый объект в `rows` описывает результат одного субъекта в одном годовом срезе. Пример целого файла — [демонстрационный набор](../examples/demo-dataset.json).

Этот формат используется локальным CLI и серверным импортом. CLI-импорт заменяет указанные периоды, загрузка из админки добавляет новые. Админка принимает исходный JSON до 2 МиБ. Соответствие полей таблицам PostgreSQL описано в [архитектуре](architecture.md).

Для веб-сравнений указывайте доступные читателю HTTP(S)-источники. Веб-клиент показывает относительное имя файла текстом.

## Корневой объект

| Поле | Тип и правило |
| --- | --- |
| `schema_version` | Целое число `1`. |
| `data_kind` | Строка `demo` или `production`. |
| `rating_id` | Стабильный идентификатор одного рейтинга. |
| `rating_title` | Человекочитаемое название рейтинга. |
| `subjects` | Непустой массив объектов с полями `subject_id` и `name`. Идентификаторы уникальны. Имена могут совпадать. |
| `snapshots` | Непустой массив срезов. Периоды уникальны. |

## Срез

| Поле | Тип и правило |
| --- | --- |
| `period` | Строка из четырёх цифр от `0001` до `9999`. В прототипе обозначает полный календарный год. |
| `methodology_version` | Идентификатор версии методики, установленный по сведениям источника. Если издатель не публикует код версии, укажите локальный ID и зафиксируйте основание в документации набора. |
| `score_min`, `score_max` | Числовые границы шкалы в баллах. Минимум меньше максимума. |
| `cohort_id` | Идентификатор подтверждённого состава и правил включения субъектов или `null`. При изменении состава либо правил включения используется новый идентификатор. |
| `population_size` | Положительное целое число. Размер полного рейтинга за период по публикации. |
| `source` | Объект с полями `title`, `reference`, `published_on` и необязательным `data_reference`. `reference` содержит HTTP(S)-ссылку на публикацию или относительный путь к доступному читателю файлу от корня проекта. `published_on` — действительная дата публикации `YYYY-MM-DD`. `data_reference` — HTTP(S)-ссылка на таблицу с точными значениями, если она опубликована отдельно. |
| `rows` | Массив строк среза. Допустима выгрузка части полного рейтинга, поэтому число строк может быть меньше `population_size`. |

## Строка среза

| Поле | Тип и правило |
| --- | --- |
| `subject_id` | Идентификатор из `subjects`. В одном срезе встречается не более одного раза. |
| `rank` | Опубликованное целое место от `1` до `population_size` или `null`. Совпадающие места допустимы. |
| `score` | Балл в пределах `[score_min, score_max]` или `null`. Больший балл означает более высокую оценку. |

## Валидация и пропуски

- Перечисленные поля обязательны, кроме `source.data_reference`. `null` допустим только для `cohort_id`, `rank` и `score`. Неизвестные поля версии `1` допускаются и игнорируются. Повторные имена свойств JSON считаются ошибкой.
- `rating_id` и `subject_id` соответствуют `[a-z0-9][a-z0-9_-]*`. Идентификаторы методики и охвата, имена, названия и ссылки должны быть непустыми строками без управляющих символов и пробелов по краям. Идентификаторы сравниваются с учётом регистра.
- Границы шкалы и баллы представляются конечными числами JSON с точностью не выше сотых. Например, `12.340` допустимо, поскольку эквивалентно `12.34`. Строки с числами, булевы значения, `NaN` и бесконечность недопустимы. Считайте баллы с точной десятичной арифметикой.
- Если строки выбранного субъекта нет в срезе, его место и балл для этого среза отсутствуют. `rank: null` и `score: null` означают пропуск соответствующего поля. Значение `score: 0` сохраняется. Число строк среза не превышает `population_size`.
- Убедитесь, что `cohort_id` назначен по методике и составу полного рейтинга. Совпадение размера совокупности само по себе не подтверждает её сопоставимость. При недостатке сведений передавайте `null`.

## Дополнительные показатели регионов

Отдельный UTF-8 JSON-файл с `schema_version: 1` и массивом `series` загружается при запуске веб-сервера. Он содержит справочные ряды для сравнения РИА. Для `group` допустимы `statistics` и `ai`. `id` уникален, значения индексируются стабильными `subject_id`. В `values` записываются десятичные строки с точкой, `null` или только известные строки. Для `ai-activity-rank` и `ai-adoption-rank` используются положительные целочисленные строки. Пары `ai-activity-rank` и `ai-activity-score`, `ai-adoption-rank` и `ai-adoption-count` образуют таблицы рейтингов ИИ. Ссылка `reference` должна использовать HTTP(S). Период хранится как подпись выпуска.

```json
{
  "schema_version": 1,
  "series": [{
    "id": "birth-rate-2024",
    "group": "statistics",
    "label": "Рождаемость",
    "period": "2024",
    "unit": "на 1 000 человек",
    "source": "Росстат, коэффициенты рождаемости",
    "reference": "https://www.rosstat.gov.ru/storage/mediabank/osn-01-2025.pdf",
    "note": "Оперативные данные за январь–декабрь по регистрации в ЗАГС.",
    "values": {"yanao": "12.8", "khmao-yugra": null}
  }]
}
```

В примере `null` демонстрирует пропуск в локальной выгрузке. Подключённые выпуски и их фактический охват перечислены в [каталоге источников](public-data-sources.md).

В веб-сравнении числовые ряды группы `statistics` с ID `birth-rate-*` выводятся на вкладке «Демография», а с ID `ai92-*` и `diesel-*` — на вкладке «Топливо». Прочие ряды этой группы появляются во вкладке «Другие показатели».
