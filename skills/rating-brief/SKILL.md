# Аналитическая справка по рейтингу

Для И16 используй [спецификацию](../../SPEC.md), [контракт данных](../../docs/data-contract.md) и [шаблон](../../docs/brief-template.md). Для похожего проекта сначала установи по его материалам, кто входит в рейтинг, где опубликованы результаты, как определяются места и баллы и какой вопрос должен решить читатель.

1. Определи текущий период, стабильные ID субъектов и базу, если она нужна. Различай состав опубликованного рейтинга и выбранную для справки группу. Сохраняй официальные места и ничьи.
2. Сверь версию методики, шкалу, подтверждение охвата, даты и доступность данных. Применяй условия сопоставимости отдельно к местам и баллам. При неполном покрытии укажи, на каких наблюдениях основан вывод.
3. Подготовь проверяемую таблицу. Пересчитай значимые изменения напрямую из исходных значений. Проверь знаки дельт и разрывов по опорному субъекту и сохранение нулевых значений. В справке с ИИ сверяй каждое утверждение с фактами, рассчитанными сервером.
4. Начни справку с ответа на вопрос аналитика. Укажи период, опорные числа, источники и ограничения, которые меняют смысл сравнения. Формулируй причины только при наличии отдельных подтверждающих данных.
5. При проектировании без выгрузки пометь предположения как рабочие, а синтетические данные явно обозначь. Для защиты И16 используй [опубликованные данные РИА Рейтинг](../../docs/pilot-ria.md) и [сценарии приёмки](../../docs/acceptance.md).
