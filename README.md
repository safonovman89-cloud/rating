# И16. Сравнение субъектов по рейтингу

И16 готовит аналитическую справку по выбранным субъектам. Справка показывает опубликованные места и баллы за выбранный период, а при наличии сопоставимого базового периода — динамику по каждому субъекту.

Веб-клиент показывает сводку, таблицы, графики и карту РИА. Сервер выполняет сравнения, а PostgreSQL хранит справочники, годовые срезы, журнал проверок и сессии. Тот же расчёт доступен через CLI, HTTP API и локальный MCP. Из админки можно добавлять рейтинги и выпуски.

## Веб-приложение

Для запуска используйте Python 3.11+ и доступный PostgreSQL. Пример ниже использует PostgreSQL 17 в Docker. На Mac с отдельным профилем Colima используйте `docker --context colima-i16` вместо `docker`.

```sh
docker run -d --name i16-postgres \
  -p 127.0.0.1:55416:5432 \
  -e POSTGRES_USER=i16 -e POSTGRES_PASSWORD=i16-local -e POSTGRES_DB=i16 \
  -v i16-rating-data:/var/lib/postgresql/data postgres:17-alpine
```

Для уже созданного остановленного контейнера выполните `docker start i16-postgres`. Подготовьте окружение и схему из корня проекта.

```sh
python3 -m venv .venv
source .venv/bin/activate
python -m pip install -r requirements.txt
export DATABASE_URL=postgresql://i16:i16-local@127.0.0.1:55416/i16
python -m i16 migrate
```

В локальном примере PostgreSQL доступен по адресу `127.0.0.1:55416`, база и пользователь называются `i16`. В клиенте PostgreSQL используйте эти значения и пароль из команды создания контейнера. Если установлен `psql`, выполните `psql "$DATABASE_URL" -c 'SELECT current_database();'`.

### Запуск с демонабором

```sh
python -m i16 import --dataset examples/demo-dataset.json
python -m i16 serve --rating-id demo-rating --port 8016
```

### Запуск с полным набором РИА

```sh
mkdir -p build
curl -fL --max-time 30 https://rfimage.ru/regional-ratings -o build/ria-source.html
python -m i16 prepare-ria --source build/ria-source.html --output build/ria-2024-2025.json
python -m i16 import --dataset build/ria-2024-2025.json
python -m i16 serve --rating-id ria-social-economic-regions --port 8016 --refresh-ria
```

Откройте [И16 в браузере](http://127.0.0.1:8016/). Без флага `--port` сервер использует порт 8000. В полном наборе РИА доступны 85 ранжированных регионов. Воспользуйтесь поиском по названию, отметьте регионы, выберите базу 2024 и нажмите «Сравнить». Дашборд обновит графики баллов, изменений места и балла и разрывов с опорным субъектом. Для автономного пилота на отдельной базе импортируйте `examples/ria-pilot-dataset.json` и запустите сервер с тем же `--rating-id` и без фонового обновления. Контрольная выборка содержит 10 субъектов из рейтинга на 85 мест.

Рейтинг РИА открывается экраном «ЯНАО за минуту» с последним выпуском и ближайшей сопоставимой базой. Готовые группы сразу формируют сравнение. Кнопка «Справка на 1 страницу» открывает печать A4, где можно выбрать «Сохранить как PDF». При ухудшении динамики раздел «Что проверить» показывает ссылки на открытые ряды Росстата.

На карте рейтинга РИА можно выбрать балл или место за текущий год. Если у сформированной справки есть база, в меню карты также доступны изменения балла и места. Нажатие на контур или выбор региона из списка открывает карточку, из которой регион можно добавить к сравнению.

В меню «Тема» в шапке можно выбрать светлую, тёмную, системную темы или «Северное сияние». Выбор сохраняется в браузере. Печатная справка использует светлую палитру.

### LLM для справки и помощника

Перед запуском `serve` задайте `I16_AI_URL` с полным адресом `chat/completions` и `I16_AI_MODEL` с именем модели. Для удалённого шлюза нужны HTTPS и `I16_AI_API_KEY`. Для локальной модели в запущенном Ollama используйте следующие команды.

```sh
ollama pull qwen2.5:1.5b
export I16_AI_URL=http://127.0.0.1:11434/v1/chat/completions
export I16_AI_MODEL=qwen2.5:1.5b
```

Для адреса loopback ключ необязателен. В справках модель выбирает формулировки из рассчитанных фактов. При недоступности модели используется шаблон с теми же числами и источниками.

Кнопка «Помощник» открывает поле для вопросов об интерфейсе. Сервер подбирает записи с учётом текущего раздела и передаёт модели вопрос и справочные сведения. Помощник показывает пометку «Ответ LLM» и ссылки на разделы. При недоступности модели он показывает подсказку из справочника.

## Обновление рейтинга РИА

С `--refresh-ria` сервер проверяет сводную таблицу при запуске и каждые 24 часа, пока работает приложение. `--refresh-ria 12` задаёт интервал в 12 часов. Статус виден на экране руководителя и доступен через `GET /api/v1/refresh`. Для разовой проверки выполните `python -m i16 refresh-ria` с заданным `DATABASE_URL`.

Проверка охватывает выпуски 2024–2025 годов. Изменившиеся срезы загружаются после проверки. При сбое сохраняются последние загруженные значения. Для подключения следующего выпуска сначала сверьте его источник, методику, состав рейтинга и контрольные значения.

## Администратор

Укажите `I16_ADMIN_PASSWORD_FILE` при запуске `serve`. Для входа используется пользователь `admin`, его имя можно переопределить через `I16_ADMIN_USER`. Например, из корня проекта создайте файл пароля с правами `0600` и передайте путь приложению:

```sh
mkdir -p build
python -c 'import os, secrets; fd = os.open("build/i16-admin-password.txt", os.O_WRONLY | os.O_CREAT | os.O_EXCL, 0o600); os.write(fd, (secrets.token_urlsafe(24) + "\n").encode()); os.close(fd)'
export I16_ADMIN_PASSWORD_FILE="$PWD/build/i16-admin-password.txt"
python -m i16 serve --rating-id ria-social-economic-regions --port 8016 --refresh-ria
```

Откройте [панель администратора](http://127.0.0.1:8016/admin/). Пароль для входа находится в указанном файле. В Postman выберите **Authorization → Basic Auth** и отправьте `POST http://127.0.0.1:8016/admin/api/v1/refresh` с телом `{}` в режиме **Body → raw → JSON**. Ответ `202` означает, что проверка принята, а `409` — что проверка уже выполняется. Для ручного запуска из панели требуется `--refresh-ria`.

Раздел аналитики показывает покрытие выпусков, пропуски и последние проверки для рейтинга, заданного при запуске. История хранится в PostgreSQL и начинается после миграции `002_refresh_history.sql`. В Postman защищённый запрос `GET /admin/api/v1/analytics` возвращает те же показатели.

В разделе «Источники данных» загрузите JSON по [контракту И16](docs/data-contract.md). Для нового рейтинга задайте новый `rating_id`. Для добавления годов сохраните ID, название и тип существующего рейтинга, имена известных субъектов и включите только новые выпуски. Ссылка в каталоге открывает сравнение по загруженному рейтингу. Максимальный размер файла — 2 МиБ. Для замены существующего среза используйте CLI-команду `python -m i16 import --dataset <путь-к-JSON>`.

## Самостоятельная регистрация

Откройте [вход по email](http://127.0.0.1:8016/login/), запросите ссылку и подтвердите вход в течение 15 минут. Первый вход создаёт учётную запись. Сессия действует семь суток, её можно завершить кнопкой «Выйти». После выбора рейтинга в каталоге настройте годы и субъекты на публичной странице сравнения.

Перед запуском примените `python -m i16 migrate`. Для отправки писем задайте `I16_SMTP_HOST` и `I16_SMTP_FROM` с адресом отправителя. По умолчанию используется STARTTLS на порту 587. Для TLS с момента подключения задайте `I16_SMTP_MODE=ssl` (порт 465). Порт можно переопределить через `I16_SMTP_PORT`. Если почтовый сервер требует вход, передайте `I16_SMTP_USER` и `I16_SMTP_PASSWORD` через окружение сервиса. Без SMTP страница входа сообщает, что отправка недоступна.

При развёртывании для других пользователей задайте `I16_AUTH_BASE_URL` как внешний HTTPS-адрес сервиса, например `https://rating.example.org`. Настройте HTTPS-прокси до локального порта И16 с сохранением внешнего заголовка `Host`. Письмо будет ссылаться на внешний адрес, а сессионная cookie получит атрибут `Secure`. Для локального теста ссылка ведёт на тот же адрес, с которого её запросили.

## HTTP API в Postman

После запуска с демонабором отправьте `GET http://127.0.0.1:8016/api/v1/comparisons?rating_id=demo-rating&period=2025&baseline=2024&subject=demo-a&subject=demo-b&subject=demo-c`. Повторяющийся параметр `subject` задаёт список ID. Для опоры добавьте `focus_subject=demo-a`. Доступные годы и ID выдаёт `GET /api/v1/rating`. Для административных операций включите Basic Auth. Доступные маршруты и коды ответа перечислены в [архитектуре](docs/architecture.md#http-api).

## Локальный MCP-сервер

После установки `requirements.txt` запустите как подпроцесс MCP-клиента `python -m i16 mcp --rating-id ria-social-economic-regions` из корня проекта с заданным `DATABASE_URL`. Транспорт — `stdio`. Поддерживаются `get_rating`, `compare_regions` и `get_map_indicators`. Пример конфигурации для клиента, который принимает `mcpServers`:

```json
{
  "mcpServers": {
    "i16": {
      "command": "/absolute/path/to/i16/.venv/bin/python",
      "args": ["-m", "i16", "mcp", "--rating-id", "ria-social-economic-regions"],
      "env": {
        "PYTHONPATH": "/absolute/path/to/i16",
        "DATABASE_URL": "postgresql://i16:i16-local@127.0.0.1:55416/i16"
      }
    }
  }
}
```

Для сравнения ЯНАО и Югры передайте в `compare_regions` `{"period":"2025","baseline":"2024","subject_ids":["yanao","khmao-yugra"],"focus_subject_id":"yanao"}`. В ответе есть опубликованные значения, динамика, разрывы, источники и краткий итог по шаблону.

## Сквозные тесты

Запустите PostgreSQL по инструкции выше и активируйте Python-окружение с зависимостями проекта. Для тестов понадобится Node.js 20 или новее. Установите зависимости и браузер один раз:

```sh
npm ci
npx playwright install chromium --only-shell
```

Для каждого прогона выполните `npm run test:e2e`. Команда создаёт отдельную базу, применяет миграции, импортирует наборы, проверяет CLI, API и веб-клиент и удаляет тестовую базу. По умолчанию используется локальный PostgreSQL из инструкции выше. Для другого подключения задайте `I16_TEST_DATABASE_URL` с ролью, имеющей право `CREATEDB`. Если нужен установленный браузер на Chromium, задайте путь к его исполняемому файлу в `I16_E2E_BROWSER`.

Журнал сервера и снимки неудачных браузерных сценариев сохраняются в `build/e2e/run-*/`. По умолчанию используются тестовые ответы ИИ. Чтобы дополнительно проверить настроенный сервис на публичной выборке РИА, задайте `I16_AI_URL`, `I16_AI_MODEL`, `I16_AI_API_KEY` и выполните `I16_E2E_LIVE_AI=1 npm run test:e2e`.

Для отдельной проверки реального вызова модели из помощника в браузере передайте те же настройки и выполните `I16_E2E_LIVE_HELP=1 npm run test:e2e`.

Для проверки подготовки и импорта всех 85 регионов и периодического обновления укажите путь к сохранённой сводной таблице. Используйте `I16_E2E_RIA_SOURCE=build/ria-source.html npm run test:e2e`. Проверка обновления подставляет локальные страницы. Вход по email проверяется через тестовый ящик.

## Локальный CLI

Команда сравнения JSON использует стандартную библиотеку Python. Она работает с локальными файлами.

```sh
python3 -m i16 compare \
  --dataset examples/demo-dataset.json \
  --subjects demo-a demo-b demo-c \
  --period 2025 --baseline 2024 \
  --output build/demo-brief.md
```

Параметр `--focus-subject` добавляет блок разрывов по выбранному субъекту. Для одного периода опустите `--baseline`.
