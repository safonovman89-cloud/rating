# И16. Сравнение субъектов по рейтингу

И16 готовит аналитическую справку по выбранным субъектам. Справка показывает опубликованные места и баллы за выбранный период, а при наличии сопоставимого базового периода — динамику по каждому субъекту.

Локальная версия состоит из веб-клиента, сервера с HTTP API и PostgreSQL. Веб-клиент показывает справку, сервер выполняет сравнение, PostgreSQL хранит исходные срезы и результаты рейтинга.

## Веб-приложение

Понадобятся Python 3.11+ и доступный PostgreSQL. Для локального запуска с Docker один раз создайте контейнер. На Mac с отдельным профилем Colima используйте `docker --context colima-i16` вместо `docker`.

```sh
docker run -d --name i16-postgres \
  -p 127.0.0.1:55416:5432 \
  -e POSTGRES_USER=i16 -e POSTGRES_PASSWORD=i16-local -e POSTGRES_DB=i16 \
  -v i16-rating-data:/var/lib/postgresql/data postgres:17-alpine
```

Для уже созданного остановленного контейнера выполните `docker start i16-postgres`. Затем в корне проекта выполните:

```sh
python3 -m venv .venv
source .venv/bin/activate
python -m pip install -r requirements.txt
export DATABASE_URL=postgresql://i16:i16-local@127.0.0.1:55416/i16
python -m i16 migrate
mkdir -p build
curl -fL --max-time 30 https://rfimage.ru/regional-ratings -o build/ria-source.html
python -m i16 prepare-ria --source build/ria-source.html --output build/ria-2024-2025.json
python -m i16 import --dataset build/ria-2024-2025.json
python -m i16 serve --rating-id ria-social-economic-regions --port 8016 --refresh-ria
```

Откройте [И16 в браузере](http://127.0.0.1:8016/). В расширенном наборе РИА доступны 85 ранжированных регионов. Воспользуйтесь поиском по названию, отметьте нужные регионы, выберите базу 2024 и нажмите «Сравнить». Дашборд обновит графики баллов, изменений места и балла и разрывов с опорным субъектом. Для автономного запуска на отдельной базе доступна контрольная выборка `examples/ria-pilot-dataset.json` на десять субъектов. Для синтетического набора загрузите `examples/demo-dataset.json` и запустите сервер с `--rating-id demo-rating`.

Рейтинг РИА открывается экраном «ЯНАО за минуту» с последним выпуском и ближайшей сопоставимой базой. Готовые группы сразу формируют сравнение. Кнопка «Справка на 1 страницу» открывает печать A4, где можно выбрать «Сохранить как PDF». При ухудшении динамики раздел «Что проверить» показывает ссылки на открытые ряды Росстата.

На карте России переключайте балл, место и их изменения, когда выбрана база. Нажатие на контур или выбор региона из списка открывает его карточку. Из неё регион добавляется к сравнению. Карта использует периоды сформированной справки.

Кнопка «Справка с ИИ» работает с серверной настройкой `I16_AI_URL` (полный HTTPS-адрес `chat/completions`), `I16_AI_MODEL` и `I16_AI_API_KEY`. Задавайте их в окружении перед запуском `serve`. При недоступности провайдера приложение показывает справку по шаблону и сохраняет все числа и источники.

## Обновление рейтинга РИА

С `--refresh-ria` сервер проверяет сводную таблицу при запуске и каждые 24 часа, пока работает приложение. `--refresh-ria 12` задаёт интервал в 12 часов. Статус виден на экране руководителя и доступен через `GET /api/v1/refresh`. Для разовой проверки выполните `python -m i16 refresh-ria` с заданным `DATABASE_URL`.

Проверка охватывает выпуски 2024–2025 годов. Изменившиеся срезы загружаются после проверки. При сбое сохраняются последние загруженные значения. Для подключения следующего выпуска сначала сверьте его источник, методику, состав рейтинга и контрольные значения.

## Локальный MCP-сервер

После установки `requirements.txt` запустите как подпроцесс MCP-клиента `python -m i16 mcp --rating-id ria-social-economic-regions` из корня проекта с заданным `DATABASE_URL`. Транспорт — `stdio`. Поддерживаются `get_rating`, `compare_regions` и `get_map_indicators`. Пример конфигурации для клиента, который принимает `mcpServers`:

```json
{
  "mcpServers": {
    "i16": {
      "command": "/absolute/path/to/i16/.venv/bin/python",
      "args": ["-m", "i16", "mcp", "--rating-id", "ria-social-economic-regions"],
      "env": {
        "PYTHONPATH": "/absolute/path/to/i16",
        "DATABASE_URL": "postgresql://i16:i16-local@127.0.0.1:55416/i16"
      }
    }
  }
}
```

Для сравнения ЯНАО и Югры передайте в `compare_regions` `{"period":"2025","baseline":"2024","subject_ids":["yanao","khmao-yugra"],"focus_subject_id":"yanao"}`. В ответе есть опубликованные значения, динамика, разрывы, источники и краткий итог по шаблону.

## Сквозные тесты

Запустите PostgreSQL по инструкции выше и активируйте Python-окружение с зависимостями проекта. Для тестов понадобится Node.js 20 или новее. Установите зависимости и браузер один раз:

```sh
npm ci
npx playwright install chromium --only-shell
```

Для каждого прогона выполните `npm run test:e2e`. Команда создаёт отдельную базу, применяет миграции, импортирует наборы, проверяет CLI, API и веб-клиент и удаляет тестовую базу. По умолчанию используется локальный PostgreSQL из инструкции выше. Для другого подключения задайте `I16_TEST_DATABASE_URL` с ролью, имеющей право `CREATEDB`. Если нужен установленный браузер на Chromium, задайте путь к его исполняемому файлу в `I16_E2E_BROWSER`.

Журнал сервера и снимки неудачных браузерных сценариев сохраняются в `build/e2e/run-*/`. По умолчанию используются тестовые ответы ИИ. Чтобы дополнительно проверить настроенный сервис на публичной выборке РИА, задайте `I16_AI_URL`, `I16_AI_MODEL`, `I16_AI_API_KEY` и выполните `I16_E2E_LIVE_AI=1 npm run test:e2e`.

Для проверки подготовки и импорта всех 85 регионов выполните `I16_E2E_RIA_SOURCE=build/ria-source.html npm run test:e2e`.

## Локальный CLI

CLI использует стандартную библиотеку Python. Для сравнения JSON база и драйвер не нужны:

```sh
python3 -m i16 compare \
  --dataset examples/demo-dataset.json \
  --subjects demo-a demo-b demo-c \
  --period 2025 --baseline 2024 \
  --output build/demo-brief.md
```

Параметр `--focus-subject` добавляет блок разрывов по выбранному субъекту. Для одного периода опустите `--baseline`.
