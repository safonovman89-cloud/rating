# Спецификация

Спецификация рабочей версии И16. Субъекты рейтинга — субъекты РФ. Контрольный сценарий использует данные РИА Рейтинг за 2024–2025 годы. Итог пилота фиксируется по [критериям приёмки](docs/acceptance.md).

## Пользовательский сценарий

Аналитик выбирает два или более субъекта и период одного рейтинга, при необходимости задаёт более ранний базовый период. И16 готовит справку, из которой видно, какое место занимает каждый субъект в опубликованном рейтинге, кто лидирует внутри выбранной группы, насколько различаются баллы и что изменилось относительно базы. Источник и ограничения видны в справке.

## FR-01. Вход и выход CLI

- Один локальный JSON-файл по [контракту данных](docs/data-contract.md). В нём есть справочник субъектов и один или несколько срезов одного рейтинга.
- CLI `python3 -m i16 compare` с обязательными аргументами `--dataset`, `--subjects`, `--period`, `--output` и необязательными `--baseline` и `--focus-subject`. Годы задаются явно.
- Один файл Markdown в UTF-8 по [шаблону справки](docs/brief-template.md). Текст строится из вычисленных значений и повторяемых формулировок. Одинаковые данные и параметры сравнения дают одинаковый текст, включая порядок строк и выводов.

## FR-02. Сравнение за период

1. Берите места из выбранного среза. Сохраняйте опубликованный номер места при любом наборе выбранных субъектов. Общее число субъектов рейтинга берите из метаданных среза.
2. Показывайте выбранные субъекты по возрастанию места. При равном или отсутствующем месте используйте идентификатор для стабильного порядка. Субъекты без места идут после субъектов с местом.
3. Определяйте лидеров выбранной группы по минимальному месту. При ничьей перечисляйте всех лидеров. Если места доступны лишь части группы, формулируйте результат как наивысшую из доступных позиций. Для этого вывода нужны как минимум два известных места.
4. Разброс баллов равен `максимум − минимум` по доступным баллам выбранной группы. Показывайте его при наличии хотя бы двух баллов. При неполном покрытии указывайте число доступных значений и размер группы.
5. Сохраняйте в таблице строку выбранного субъекта, даже если в срезе её поля отсутствуют. Показывайте пропуск как `—`, а результат помечайте как частичный при пропуске любого запрошенного значения. Нулевой балл сохраняйте как значение.

## FR-03. Динамика

Базовый период указывается явно и должен предшествовать выбранному. Без базы справка показывает сравнение за один период.

| Показатель | Условия                                                                                                                                                                                                           | Формула и интерпретация                                                                             |
| -------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ | ------------------------------------------------------------------------------------------------------------------------ |
| Балл             | Одинаковая версия методики, одинаковые границы шкалы, оба значения известны                                                                             | `балл текущий − балл базовый`. Плюс означает рост балла.                   |
| Место           | Те же версия методики и шкала, подтверждённый одинаковый `cohort_id`, одинаковая численность рейтинга, оба места известны | `место базовое − место текущее`. Плюс означает улучшение позиции. |

Если версия методики или границы шкалы различаются, покажите опубликованные значения обоих периодов, отметьте причину и опустите обе дельты. Если отличается охват или его сопоставимость не подтверждена, опустите дельту места. Изменение балла остаётся доступным при выполнении условий для балла. Пропуск исходного значения влияет только на связанную дельту. Любая недоступная дельта делает справку частичной. Изменения места и балла описывайте отдельно. Причинные выводы требуют дополнительных данных и выходят за рамки прототипа.

## FR-04. Ошибки и сохранение

- Отклоняйте некорректный JSON, нарушение контракта, неизвестные или повторные ID в запросе, выбор менее двух субъектов и ненайденный период. Отсутствие всех текущих мест и баллов в выбранной группе — ошибка. При одном доступном значении формируйте частичную справку.
- При ошибке ввода выводите понятное сообщение в `stderr` и возвращайте код `2`. При ошибке чтения или записи возвращайте код `1`. Успешный результат, включая частичную справку, возвращает `0`.
- По указанному пути можно сохранить новый результат или заменить прежнюю справку целиком. При записи создавайте родительский каталог по необходимости. При ошибке существующая справка должна сохраниться, а новый файл — отсутствовать. Входной файл должен оставаться доступным и неизменным. Если пути ввода и вывода указывают на один файл, отклоните запрос с кодом `2`.

## FR-05. Визуальное оформление

Используйте [визуальный стиль И16](docs/visual-style.md) и [HTML-макет](examples/rating-preview.html). Сохраняйте читаемость на 375 px и при печати A4. Периоды, источники и знаки дельт должны быть понятны по тексту и числам.

## FR-06. Хранение и импорт

PostgreSQL хранит несколько рейтингов. Один JSON-файл описывает один рейтинг и один или несколько его годовых срезов. Разворачивайте схему миграциями. CLI-импорт атомарно заменяет указанные срезы, а загрузка из админки добавляет новые срезы по FR-18. Каждый запрос сравнения использует один рейтинг.

## FR-07. HTTP API

Сервер возвращает справочник и результаты сравнения по [контракту HTTP API](docs/architecture.md#http-api). Веб-клиент показывает ответ API. Сервер, CLI и MCP вызывают общий модуль сравнения. Частичная справка возвращается с кодом `200`. Баллы и разрывы передаются десятичными строками, пропуски — как JSON `null`.

## FR-08. Параметры веб-сравнения

После изменения периода, базы, состава субъектов или опорного субъекта рядом с видимой справкой показывайте «Параметры изменились. Нажмите „Сравнить“». В печатной версии справки сохраняйте предупреждение. Убирайте его, когда параметры снова совпадают с показанной справкой или получен новый результат. Вкладка И16 использует значок приложения.

Во время пересчёта и после ошибки оставляйте последнюю успешную справку доступной. Предупреждение продолжает сравнивать параметры формы с показанной справкой. На время запроса блокируйте повторный запуск, печать компактной справки и добавление субъекта с карты.

При расширенной загрузке РИА за 2024–2025 годы доступны все 85 ранжированных субъектов за оба года. Сверяйте опубликованные места и баллы с контрольной выборкой и сохраняйте её ID. В веб-форме можно найти субъект по названию. Смена поискового запроса сохраняет отметки и опорный субъект.

## FR-09. Разрывы по опорному субъекту

Опорный субъект должен входить в выбранную группу. Разрыв равен баллу опоры минус балл другого субъекта за тот же период. При сопоставимых методике и шкале покажите изменение разрыва между базовым и текущим периодами. При пропуске одного из баллов соответствующий разрыв недоступен. Без опорного субъекта блок разрывов отсутствует.

## FR-10. Справка с ИИ

Сервер рассчитывает факты и формирует допустимые варианты фраз. Модель выбирает их порядок и формулировки, а сервер проверяет ID, индексы и наличие обязательных фактов. При недоступной модели или недопустимом выборе используется шаблон. В обоих режимах таблица, источники и ограничения происходят из одного расчёта.

## FR-11. Аналитический дашборд

Дашборд показывает баллы выбранных субъектов за текущий период. При выборе базы появляются графики изменения балла и места. При выборе опорного субъекта появляется график разрывов за текущий год. Графики используют те же строки, порядок субъектов, периоды и значения, что соответствующие таблицы справки.

Полосы показывают величину от нуля, по разные стороны для положительных и отрицательных значений. Знаки и точные числа видны рядом с полосами. Недоступное значение обозначается `—`. При отсутствии сопоставимых значений график показывает пустое состояние, причины указаны в ограничениях справки.

## FR-12. Экран и справка для руководителя

При открытии рейтинга РИА показывайте ЯНАО и Югру за последний выпуск с ближайшим подтверждённо сопоставимым базовым выпуском, если он есть. Над формой выведите место опорного региона в полном рейтинге, балл и разрыв. Для ЯНАО при наличии Югры показывайте разрыв с ней, в остальных случаях показывайте разрыв с первым соперником в порядке таблицы. Показывайте доступную динамику, периоды и источник. При изменении параметров отмечайте устаревшие результаты и отключайте кнопку компактной справки до успешного сравнения или возврата параметров.

Готовые группы сокращают выбор до одного клика. Доступны ЯНАО с Югрой, ЯНАО с регионами УрФО и ЯНАО с субъектами на первых трёх опубликованных местах текущего периода. При выборе группы устанавливайте ЯНАО опорным и сразу пересчитывайте справку с выбранными периодами.

Кнопка «Справка на 1 страницу» открывает печатный вид A4 для сохранения PDF. Он содержит главные цифры, компактную таблицу, график ключевого разрыва и источники. В таблице оставляйте до пяти строк в исходном порядке, включая опорный субъект, и указывайте число строк полной справки при сокращении. Обычная печать выводит полную справку.

В печати рабочего рейтинга добавляйте фотографию опорного региона из локального каталога. Без опоры используйте регион из первой строки показа. Под фотографией указывайте название снимка, автора, лицензию и ссылку на файл-источник. При недоступном снимке печатайте справку с доступными данными. Одностраничная справка с фото сохраняет формат A4.

Рядом с кнопкой одностраничной справки показывайте поле «Регион для PDF» со списком субъектов из сформированного сравнения. Оно показывает текущего героя отчёта. Выбор другого региона делает его опорным и запускает пересчёт. Для заголовка, цифр и фотографии используйте один результат пересчёта.

При ухудшении доступной динамики места или балла опорного региона показывайте раздел «Что проверить». Указывайте текущий год и ссылки на ряды Росстата по занятости, реальным доходам и инвестициям как направление проверки. Причины изменения балла РИА требуют подтверждения данными издателя.

## FR-13. Карта регионов России

В рейтинге РИА показывайте интерактивную карту с местами и баллами за год сформированной справки. При указанной базе доступны изменения места и балла. Сопоставляйте контуры и данные по стабильным ID. При отсутствии показателя используйте отдельный цвет и подпись «Нет данных». В легенде указывайте шкалу, а рядом с картой указывайте периоды и источники показателей и границ.

Пользователь может выбрать регион на карте или в списке и увидеть его опубликованные значения за оба периода с доступными дельтами. Из карточки регион добавляется к текущему сравнению с сохранением других выбранных субъектов и опоры. Цвет карты применяется ко всем доступным регионам. Выбор группы сравнения выделяет её контуры. Ошибка загрузки карты допускает повтор и не блокирует справку.

## FR-14. Периодическая загрузка данных РИА

При включённом расписании веб-сервер проверяет сводную таблицу сразу после запуска и затем каждые 24 часа по умолчанию. Интервал можно переопределить. Используйте при загрузке те же правила проверки источника, что в `prepare-ria`. Загружайте только отличающиеся проверенные срезы. При недоступности источника, неизвестных периодах и некорректных данных продолжайте работу с сохранёнными срезами. Показывайте состояние, время последней проверки и следующее запланированное время. Разовый запуск доступен через CLI.

Новый выпуск подключается после сверки источника, методики и охвата. Периодическая проверка обслуживает выпуски 2024–2025 годов, пока для нового выпуска не настроено подтверждённое правило подготовки.

## FR-15. Локальный MCP-сервер

Предоставьте MCP-клиенту по `stdio` справочник, сравнение по выбранным субъектам и показатели карты за выбранные периоды. Сервер читает выбранный рейтинг из PostgreSQL и использует те же расчёты и форматы числовых значений, что HTTP API. Ошибки параметров и недоступность базы возвращаются как ошибки вызова. Подключённые инструменты работают на чтение.

## FR-16. Вход администратора

На локальном веб-сервере защитите панель `/admin/` и ручной запуск проверки источника HTTP Basic Auth. Имя задаётся при запуске, пароль читается из локального файла. При отсутствии настроенных учётных данных панель недоступна. Неверные или отсутствующие учётные данные дают `401`. Просмотр рейтинга, статус расписания и вызовы MCP чтения сохраняют существующий доступ.

Администратор видит состояние проверки и может запросить проверку сейчас, если включён обработчик обновления РИА. Ручная проверка проходит через тот же обработчик и правила валидации, что расписание. Одновременные запросы не запускают параллельные проверки.

## FR-17. Аналитика администратора

На защищённой панели показывайте количество регионов, выпусков и загруженных наблюдений для рейтинга, заданного при запуске сервера. Для каждого выпуска указывайте число загруженных и полностью заполненных строк относительно опубликованного размера, пропуски места и балла среди загруженных строк и дату публикации. Считайте показатели по данным PostgreSQL.

Сохраняйте в PostgreSQL завершённые проверки РИА с временем, способом запуска, исходом, длительностью и сообщением об ошибке. Показывайте итоги за последние 30 суток и десять последних записей. История начинается с подключения журнала. Ошибка записи журнала диагностируется отдельно и не меняет исход проверки.

## FR-18. Добавление источников через админку

На защищённой панели показывайте источники загруженных выпусков и принимайте JSON по контракту И16. Для каждого выпуска сохраняйте указанное название источника, ссылку и дату публикации. Импорт добавляет новый рейтинг или новые выпуски существующего рейтинга. Совпадение года с загруженным выпуском, конфликт названия рейтинга, типа данных или имен субъектов и невалидный файл отклоняйте целиком. Подготовленный файл служит входом, данные загружаются транзакционно.

После импорта дайте ссылку для просмотра рейтинга. Идентификатор в ссылке выбирает рейтинг для справочника, сравнений, карты и справок. Тот же выбор доступен через параметр `rating_id` HTTP API. Рейтинг по умолчанию и расписание проверки РИА настраиваются при запуске сервера.

Загружайте каталог источников при открытии админки независимо от запроса состояния плановой проверки. После успешного импорта или завершения проверки обновляйте данные панели.

## FR-19. Регистрация и рабочая область аналитика

Пользователь вводит email и подтверждает его одноразовой ссылкой из письма. Ссылка действует 15 минут. Первое подтверждение создаёт учётную запись, повторное позволяет войти в неё. Сессия действует 7 суток и прекращается при выходе. Ссылки и сессии хранятся в PostgreSQL в виде хешей. Письма отправляются через настроенный SMTP.

В рабочей области пользователь видит каталог доступных рейтингов и переходит к выбору периода, субъектов и построению сравнения. Доступ к рабочей области требует сессии. Импорт источников требует отдельного входа администратора. Обычная страница рейтинга остаётся доступна по своему адресу.

## FR-20. Помощник по сервису

На странице рейтинга, при входе, в рабочей области и админке доступен помощник с полем для вопроса на русском языке. Сервер подбирает записи справочника с учётом текущей страницы и передаёт настроенной языковой модели вопрос и найденные объяснения. Модель поясняет назначение разделов и полей своими словами и даёт конкретные шаги. Когда подходящих записей несколько или совпадений нет, модель также получает контекст страницы и указывает идентификаторы подходящих записей. Сервис проверяет ответ и формирует ссылки из справочника.

Помощник показывает источник ответа. При недоступности модели или некорректном ответе доступна подсказка из справочника. Для вопроса вне тем сервиса показываются подходящие примеры.

## FR-21. Тема веб-интерфейса

В шапке рейтинга, страницы входа, рабочей области и админки доступны системная, светлая, тёмная темы и «Северное сияние». При первом открытии используется системная тема. Выбор применяется сразу и сохраняется в браузере для всех страниц И16. Фон, текст, поля, графики, карта и диалог помощника используют выбранную палитру. Смысл шкал и знаков сохраняется. Печатная справка использует светлую палитру.

## FR-22. Дополнительные показатели по регионам

В сравнении РИА веб-сервис показывает отдельно от рейтинга значения рождаемости, потребительских цен на топливо и опубликованные результаты по ИИ для выбранных субъектов. Значения связаны с `subject_id`, у каждого показателя видны его собственный период, единица и первоисточник. Места берутся из публикации или описывают явно указанную выборку. При отсутствии значения показывается пропуск. Дополнительные показатели не влияют на места, баллы и динамику РИА.

Для сотовой связи доступны карты операторов. Доля населения с покрытием указывается только при наличии сопоставимой региональной выгрузки с явно определённой технологией. В карточке ИИ различаются опубликованные случаи внедрения и индексы активности, отражающие исследования, спрос на кадры и другие показатели.

## FR-23. Обратная связь

Со страницы рейтинга можно отправить разработчику текст сообщения и по желанию оставить email для ответа. Сервер проверяет поля и сохраняет сообщение в PostgreSQL. Подтверждение появляется после записи. При ошибке введённые данные сохраняются в форме. Разработчик просматривает сообщения и контактные адреса в защищённой админке.

## FR-24. Вкладки и итоговая справка

У сравнения РИА есть вкладки «Рейтинг», «Демография», «Топливо», «Связь», «ИИ» и «Итоговая справка». Вкладки используют последний успешно сформированный состав регионов и сохраняют выбор вкладки при пересчёте. Управление доступно клавиатурой. При отсутствии ряда вкладка показывает отсутствие данных.

Итоговая справка объединяет краткий итог, таблицу рейтинга, доступные разрывы и тематические разделы выбранных регионов. Каждая таблица сохраняет исходные значения, периоды, пропуски и ссылки на публикации. Кнопка на вкладке открывает печать одного PDF A4 со всеми разделами и доступной фотографией опорного региона. Пока параметры изменены без пересчёта, кнопка недоступна. Одностраничная справка для руководителя и обычная печать остаются доступны по FR-12.
